# 💸 FinLog - Expense Tracker

FinLog is a simple and user-friendly Flask-based expense tracking web application. It helps you track your daily expenses, filter them by category, and visualize spending with a pie chart.

---

## 🚀 Features

- Add new expenses with category, note, amount, and date.
- View all expenses in a table.
- Filter by:
  - Category
  - Note (search)
  - Date range
- View total expenses.
- View category-wise spending breakdown (Pie Chart).

---



## ⚙️ Tech Stack

- **Backend**: Flask
- **Database**: MySQL
- **Frontend**: HTML, CSS, Bootstrap
- **Charting**: Chart.js
- **Others**: python-dotenv for environment variables
